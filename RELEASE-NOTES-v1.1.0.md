# v1.1.0 — one-click portable Windows package

Download `downloads/Codex-Project-Recovery-One-Click-Windows.zip`, extract the entire package, and double-click `START-RECOVERY.bat`. If Codex is open, the tool prompts you to quit and waits before continuing. It creates rollback backups before changing project organization.

No Python installation or administrator access is required. Windows 10/11 x64 only.

This unofficial community tool targets one symptom: local Codex projects missing from the desktop sidebar while the chats still appear in Recents. It cannot recover records removed from all saved sources. See the repository README and `START-HERE.txt` in the ZIP for full setup instructions and limits.

The ZIP SHA-256 is available in `downloads/Codex-Project-Recovery-One-Click-Windows.zip.sha256`.
