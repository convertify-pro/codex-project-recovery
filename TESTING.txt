PORTABLE EDITION v1.1.0

18 automated tests passed using the bundled isolated runtime:
- diagnosis is read-only for Codex records
- existing projects, memberships, renamed projects and unrelated settings survive
- chat bodies are preserved
- repeated recovery is a no-op
- ambiguous roots, subagents and explicit projectless chats are skipped
- conflicting existing memberships are preserved
- damaged saved files are skipped; unsupported database layouts stop
- concurrent state/database changes stop the repair
- snapshots exclude chat text and account state
- organization undo preserves newer conversation text
- newer desktop state prevents automatic undo
- open apps prevent mutation
- failed state writes roll back database membership changes
- automatic mode needs no setup/RESTORE prompt
- waiting mode explains how to close Codex and continues automatically
- automatic repeat runs save a snapshot without rewriting organization
- diagnosis mode can run without closing the app
- the private runtime is isolated from installed Python/site-packages

Runtime smoke checks passed: startup, SQLite, SHA256, ctypes, subprocess,
and diagnostic execution. The core recovery was also tested on an isolated
copy of a damaged installation's records; all non-membership thread fields
were preserved and SQLite integrity checks passed.

Additional release checks cover an extracted path containing spaces, a PATH
without a system Python, runtime licenses, and a private-data exclusion scan.

These checks do not certify every Windows/app version or prevent future bugs.
